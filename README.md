# testscripts

Esta carpeta contiene scripts en prueba. A continuación, se describen algunos de los archivos más relevantes:

- **`admin.py`**: Aplicación gráfica en Python que permite ejecutar scripts desde una interfaz con `tkinter`. También muestra un logo descargado desde una URL.
- **`calculadora.py`**: Calculadora básica con interfaz gráfica creada con `tkinter`. Permite realizar operaciones aritméticas simples.
- **`noclosedcolab`**: Script en JavaScript que mantiene activa una sesión en Google Colab simulando un clic en un botón cada 10 minutos.

Cuando los scripts sean funcionales, se moverán a la carpeta `scripts_ok`.
